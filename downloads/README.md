# HYGIEIA для 3D-печати

[Скачать STL](https://github.com/Makismax2020/-/raw/refs/heads/main/downloads/HYGIEIA_200mm.stl)

[Скачать ZIP с STL, превью и инструкциями](https://github.com/Makismax2020/-/raw/refs/heads/main/downloads/HYGIEIA_3D_print.zip)

Размер модели: 200 × 46 × 7 мм. Подложка — 2 мм, рельеф — 5 мм. При импорте в слайсер выберите миллиметры и положите плоскую подложку на стол принтера.

STL проверен: одна замкнутая деталь, без открытых рёбер, вырожденных и дублирующихся треугольников. Физическая печать не выполнялась. Контуры букв приближены к исходному изображению шрифтом Nimbus Roman Bold. Золотой цвет в превью не сохраняется в STL.

Если репозиторий закрытый, для скачивания войдите в GitHub под учётной записью с доступом.
